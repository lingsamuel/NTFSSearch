# 0.10.0 退出快照压缩验收

在同一台 Windows 主机上只读使用九卷快照，包含 35,082,805 条有效目录项。未压缩组使用 0.9.3 的快照代码，压缩组使用 0.10.0 的正式代码。两个保存阶段输入同一批内存索引，均流式序列化、校验和刷盘后原子提交。恢复以最多三个并行任务重建各列排序。

| 方式 | 快照大小 | 完整保存 | 加载并重建排序 |
| --- | ---: | ---: | ---: |
| 未压缩 | 1,970,970,531 B（1.84 GiB） | 6.01 秒 | 35.22 秒 |
| 分卷 Zstd 等级 3 单线程 | 655,347,769 B（625.0 MiB） | 12.65 秒 | 36.34 秒 |

压缩后保留约 33.25% 的体积，少写约 1.23 GiB。九个卷解压后的内容均与未压缩组的卷块 SHA-256 一致。实际恢复验证了各卷身份、USN 日志和水位以及有效条目数一致。

保存阶段采样的进程峰值私有内存分别为约 3,844 MiB 和 3,903 MiB。进程进入两次保存阶段时的私有内存基线不同，峰值差包含运行时保留的内存。加载阶段也是同进程的两次单次测量，未固定系统缓存状态。上述加载时间不包括 USN 补读和窗口启动。

245 项测试与 Windows 桌面验证通过。测试覆盖按卷恢复、压缩块损坏、保存取消时保留原快照和正常退出流程。
