# 0.8.0 空间分析验收

在 Windows 上只读加载现有 0.7.0 退出快照，其中九个 NTFS 卷共 34,839,911 条目录项。每次只构建一个卷的空间统计。九卷卷根的逻辑字节数均与逐项累加可见文件记录的结果一致。下钻读取卷根最大的目录，其合计与卷根显示的对应条目一致。

表中时长从卷索引加载完成后开始测量，覆盖后端汇总和结果构造。窗口渲染、进程间传输和合并通知的等待时间需另行测量。更新数据由受控事务追加一个 123,456 B 的卷根文件生成，九卷更新后均精确增加 123,456 B。采样过程只读取快照，使用的是内存事务。额外托管内存按每卷创建统计前后收集垃圾后的活对象差估算，前台运行不强制收集。

237 项解决方案测试通过。Windows 便携版的真实 WebView2 窗口测试用演示索引验证了卷根和目录字节数、矩形尺寸、面包屑、返回搜索后的滚动位置，以及搜索、文件操作和退出回归。
