# 0.7.0 Windows 退出快照验收

在同一台 Windows 主机读取旧版九卷 V4 基线，共 34,842,582 条记录。旧数据库只作为读取源，写入目标位于隔离的验证目录。新快照重新加载后九卷总计仍为 34,842,582 条。恢复最多同时处理三个卷，完成的卷先返回。

| 项目 | 结果 |
| --- | ---: |
| 新快照大小 | 1,956,455,236 字节（约 1.82 GiB） |
| 写出快照并原子提交 | 14.90 秒 |
| 加载快照并重建四列排序 | 55.64 秒 |

`NtfsSearch.Cli bench-exit <旧版 Data 目录> <测试退出快照>` 可复测。此次耗时包含打开、校验和构建查询结构，旧版基线读入耗时单独记录。样本使用已保留的九卷基线，计时覆盖快照路径。

232 项核心测试通过，覆盖原始 UTF-16、硬链接身份、排序重建、损坏卷隔离、并行载入和内存合并后的目录改名。Windows 便携程序窗口自检覆盖按类型图标、按视口加载、查询、排序、分页和正常退出握手。新的管理员采集链路另需在 Windows 授权后测量实盘初扫、持续 USN 更新和稳态 Data 写入总量。
