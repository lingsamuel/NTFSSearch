# 0.15.0 搜索目录大小测量

在 Windows 上只读加载一份现有退出快照副本，共 9 卷、33,892,076 条记录。对照以同一进程、同一份已发布索引的普通搜索路径为基线。每次返回当前页最多 200 行，并计算精确命中数。初次汇总同时循环请求三种普通搜索，查询结束后留 70 ms 再发下一次请求。目录汇总每次只处理一卷，执行用户查询时在分段检查点暂停。

| 按名称搜索 | 同轮基线 P95／P99，ms | 首次汇总期间 P95／P99，ms | 稳态 P95／P99，ms | 受控更新期间 P95／P99，ms |
| --- | ---: | ---: | ---: | ---: |
| 空查询 | 0.33／0.36 | 0.52／0.69 | 0.31／0.35 | 0.50／0.50 |
| `readme` | 155.1／162.1 | 149.9／168.9 | 147.9／149.6 | 175.4／175.4 |
| `C:\Windows\` | 167.2／178.2 | 168.6／169.2 | 169.6／170.0 | 206.7／206.7 |

基线和稳态各取每种查询 21 个样本。首次汇总期间取 26 至 27 个样本。更新期间取 7 至 8 个样本，尾部数字对应其中最慢一次。按大小混排的稳态中，空查询 P50 为 0.44 ms，`readme` 为 124.2 ms，`C:\Windows\` 为 159.7 ms。

首次汇总期间，九卷合计约 14.0 秒，单卷约 0.24 至 5.25 秒，包括让位给用户查询的时间。统计完成后，额外保留的托管活对象约 963 MiB。诊断回收后私有内存增量约 637 MiB。逐卷结束时采样到的最大私有内存增量约 697 MiB。

受控更新从已加载的最大卷选取一个已有文件，在内存中提交 60 次文件大小变化。每批从发布搜索视图到目录统计可用的 P50 为 0.14 ms，P95 为 161.5 ms，P99 为 191.3 ms。长尾包含等待前台查询完成。整个实验只读取快照副本并在内存中应用变更。

这些时长覆盖后端匹配、计数、排序、分页和构造搜索行。IPC、WebView2 渲染和真实 USN 通知延迟未包含在快照采样中。Windows 真实窗口用演示索引验证了目录大小的显示、精确字节数、文件与目录混排，以及返回搜索与退出。核心测试覆盖大量目录命中、双向跨页、硬链接、缺失值、实时更新和合并，HTTP／CLI 测试覆盖原有筛选契约。

文件独占的宽查询按大小排序时，可能需要检查涉及卷的完整目录排列，以确认没有目录命中。上表未单独采样这种组合。
