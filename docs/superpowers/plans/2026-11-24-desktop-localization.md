# 桌面本地化实施计划

**目标** 为桌面应用提供跟随系统及显式语言选择，并支持贡献者通过语言文件添加翻译。

**实现** Vue、.NET 桌面会话和 Tauri 打包同一组 JSON。已保存语言通过桌面设置状态同步，现有搜索及索引流程继续使用原入口。

- [x] 先用定向后端及窗口用例验证语言配置、切换和持久化。
- [x] 在 Vue 接入共享词典，新增通用标签并切换界面文案、无障碍名称和数字格式。
- [x] 在 .NET 桌面会话接入语言选择、持久化和索引状态，向 Tauri 和 Vue 同步当前生效语言。
- [x] 在 Tauri 接入启动提示和托盘标签，跟随已保存的语言更新。
- [x] 合并内置词典，接入构建时检查并更新贡献指南和手册。
- [x] 核对当前版本并交付 Windows 便携版。
