# 桌面界面重构实施计划

**目标**　交付使用 Tauri 和 Vue 的 Windows 便携搜索工具。

**架构**　Tauri 管理同目录的 .NET 进程，通过标准输入输出传递逐行 JSON。C# 后端继续负责索引、查询、分页和 Windows 文件操作，Vue 负责显示与交互。

## 后端迁移

- [x] 先用真实子进程测试请求、计数、四列排序、翻页和退出，验证旧程序缺少桌面通信。测试使用既有 `DemoData`。
- [x] 迁移 `NtfsSearch.App` 的自动卷加载和诊断入口，去掉 WPF 工程设置与 Dispatcher，保留采集进程参数及缓存目录解析。
- [x] 使用现有 `QueryRefreshState` 串行应用操作和快照通知，合并后台刷新，使用取消令牌取消过时查询。每次发布最多 200 行，行标识保留原始 UTF-16 路径以支持文件操作。

## 桌面界面

- [x] 在 `src/NtfsSearch.Desktop` 建立 Vue 和 Tauri 工程。Rust 启动、转发并回收 .NET 进程，Vue 用请求序号应用最新结果。
- [x] 实现搜索框、键盘与菜单、四列表头排序、底栏翻页和索引详情。切换结果时保留可用的滚动位置与选中行，并显示数据加载、空结果和失败状态。

## Windows 交付

- [x] 更新 `scripts/build-windows.ps1` 和使用说明，保留旧发布包的 `app/Data` 相对位置，构建 x64 便携包。
- [x] 执行现有 .NET 测试、进程通信冒烟和 Windows 窗口验收。用固定输入和旧版对照，记录界面、后端与 WebView2 的查询延迟及内存。
