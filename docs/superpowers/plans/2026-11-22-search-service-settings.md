# 设置页与搜索服务管理实施计划

**目标** 通过窗口和托盘管理本机 HTTP 服务，并使用一行 curl 查询真实文件。

**架构** Vue 通过现有桌面通信管理后端持有的 HTTP 监听。监听启停独立于索引进程和查询目录。桌面和 CLI 共用便携版设置及端口解析。

## 搜索服务与配置

- 扩展现有设置读取和原子保存，保留旧配置默认值。增加启用状态和端口，CLI 共用端口解析及已有环境变量覆盖。
- 由桌面后端串行处理服务启停和重启。新端口先绑定成功再替换旧监听，保存失败时保留原设置。将状态通过桌面消息发送给 Vue。
- 用隔离的演示后端验证启停、重启、有冲突的端口、成功切换、启动恢复和 CLI 配置解析。

## 桌面设置页

- 在原窗口添加独立设置视图。主界面入口和原生托盘菜单通过现有 Tauri 事件进入该视图，返回时显示之前的界面。
- 设置页显示启用状态、保存端口、实际地址、错误和操作按钮。用实际端口生成一行 curl 搜索示例，待命令可用时提供复制按钮。
- 构建 Windows 便携版，验证本次相关的界面行为和版本，更新随包手册。
