# 退出快照和文件类型图标实施计划

运行时由普通权限后端持有搜索索引，管理员进程读取 NTFS 并通过本地进程间通信发送数据。正常退出时把已发布的有效文件记录和 USN 水位保存成一个文件。

- [x] 实现多卷退出快照。流式输出有效记录、校验及水位，读取时按卷重建排序。覆盖损坏卷、原始名称和无需持久排序的格式。
- [x] 用本地内存通信替换桌面采集链路的磁盘传输。通过现有 MFT 和 USN 读取路径采集，按卷发布、合并、续读、恢复并支持取消。
- [x] 用 Windows Shell 查询扩展名对应的类型图标。复用缓存并接入现有结果表。
- [x] 将正常窗口关闭接到后端保存协议，等待提交并测试直接断开时的退出行为。更新用户说明与发布版本。
- [x] 运行单元测试、Windows 构建和窗口自检。用九卷约 3500 万条记录核对退出快照格式、大小、保存速度和逐卷恢复。
- [ ] 在 Windows 授权后实测普通权限窗口与管理员采集进程的完整链路，并记录实盘稳态 Data 写入量。
