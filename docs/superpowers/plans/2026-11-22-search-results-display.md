# 搜索结果显示实施计划

**目标** 在名称和完整路径显示加粗命中，兼容两种路径分隔符，修复加宽结果表后的横向滚动。

**架构** 查询解析统一路径分隔符。桌面后端按当前页结果生成完整路径的 UTF-16 命中区间，Vue 用相同区间渲染路径和名称。结果容器的宽度由工作区约束，表格保留用户拖动后的列宽。

- [x] 增加搜索用例，验证正斜杠、反斜杠和混用路径与现有查询等价。验证多词、连续短语、目录限定、仅名称和重叠命中。先在原版本复现差异。
- [x] 在共享查询解析中归一化路径分隔符，生成当前页命中区间并传给 Vue。复用现有结果表渲染纯文本和加粗片段。
- [x] 在真实 WebView2 窄窗口验证拖宽列、搜索框和底栏位置以及纵向和横向滚轮。约束工作区宽度，将结果区内的 Shift 加纵向滚轮转换成横向移动。
- [x] 更新随包手册和版本，运行受影响的搜索用例与 Windows 结果表回归。使用现有脚本构建便携版，确认发布文件和版本，提交本轮改动。
