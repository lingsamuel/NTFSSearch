# 桌面高级搜索实施计划

**目标**　在桌面提供快捷类型筛选、高级搜索和顶部菜单，同时保留空间分析的快捷入口。

1. 在搜索测试覆盖跨卷的文件／文件夹和后缀筛选、元数据组合与分页，以及后缀列表随索引发布更新。扩展现有 SearchFilter 与 SearchCatalog，复用内存索引，保留无条件查询路径。
2. 通过 DesktopSession 把筛选传到所有查询和翻页，加入异步后缀列表请求和创建时间索引状态。范围转换为现有 SearchFilter 的 UTC ticks 和逻辑字节。
3. Vue 提供应用内搜索和工具菜单，使用多选下拉放置快捷类型筛选，并以独立对话框提交高级条件。沿用现有空间分析切换。
4. 更新用户手册并同步版本。只运行受影响的搜索测试和桌面窗口专项，使用仓库脚本生成 Windows 便携包。
