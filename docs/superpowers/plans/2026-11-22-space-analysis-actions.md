# 空间分析右键操作实现计划

**目标**是在现有矩形树图中使用 Windows 文件操作，并随时排除和恢复条目。

- 为 `SpaceUsageIndex` 添加按视图使用的排除集合。用 `SpaceUsageTests` 覆盖排除对祖先、其他分组、硬链接与实时更新的影响。继续复用未筛选的目录合计和有效索引行。
- 在 `SpaceAnalysisSession` 保存按卷分组的排除项和版本号。通过现有桌面消息通道增删规则，随树图发布恢复列表，关闭时清空。打开操作继续经过 `DesktopFileActions`。
- 在 `SpaceAnalysis.vue` 添加右键操作和恢复列表。共用自适应大小和百分比格式，移除额外描边。同步使用说明和版本，运行现有 Windows 便携构建并核对产物。
