# 搜索索引仅在正常退出时保存

## 运行期间

NTFS 是文件元数据的来源。搜索进程在内存中维护索引和四列排序。文件变化继续通过 USN 增量更新内存视图，已删除或替换的记录由后台分批合并回收。旧查询可以完成对已发布视图的读取，新查询使用最新视图。

普通权限搜索进程和管理员采集进程通过有界的本地进程间通信传递卷数据和连续的 USN 批次。复用现有卷发现、文件身份与硬链接解析、目录变更及查询逻辑。初扫期间并行接收扫描数据和该卷的 USN 批次，以完成初扫后能够连续应用的水位为准发布索引。消费落后时暂停继续取数，恢复后从尚可读取的 USN 水位继续。发现日志缺口时重新采集该卷。运行期间取消写盘捕获文件、增量日志、周期检查点和采集状态文件。

## 退出与重启

正常退出时，每个卷固定一份可查询视图和与之对应的已应用 USN 水位。流式写出一个完整的多卷快照，保存当前文件记录、目录身份、名称、路径、大小、修改时间、硬链接和各卷的日志标识及水位。排序排列、搜索结果和已被替换的历史记录只用于运行时处理。

窗口在正常退出时显示保存进度，并等待后端提交快照。临时文件写完后原子替换正式快照，正式文件始终是一份。异常中断可以沿用最近一次成功退出的文件；没有可用快照的卷从 NTFS 重建。仍在初扫、尚未取得完整视图时退出，保留已有的完整文件供下次启动。

启动时按卷并行验证和载入快照，在内存中重建名称、路径、大小和修改时间的排序，随后从保存的 USN 水位补齐变化。各卷可以独立就绪，快照中损坏或日志缺失的卷从 NTFS 重新采集。快照目录无法读取时重新发现并采集各卷。冻结视图之后发生的变化由下次启动时的 USN 补读处理。

## 升级

旧版索引文件由用户自行处理。新版读取自己的退出快照，首个启动会话从 NTFS 采集各卷。新版只管理自己的当前快照和本次保存的临时文件。

## 文件图标

在结果表中按文件扩展名使用 Windows 类型图标。后台提取小图标并按扩展名复用结果。类型图标尚未返回或系统查不到时显示通用文件图标，目录继续显示目录图标。

## 验收

在 Windows 上用约 3500 万条记录验证正常启动、持续增删改、四列排序和精确计数。用持续变更的回放验证内存中失效记录能被回收。分别记录启动排序时间、稳定运行的索引磁盘写入量、退出保存时间和最终快照大小。覆盖保存中进程异常结束、部分卷损坏、USN 历史回收、关机后变更补读和旧版缓存迁移。核对正常退出后的文件只有一份快照，并通过快照格式确认没有排序排列。
