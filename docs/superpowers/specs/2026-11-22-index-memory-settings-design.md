# 索引内存设置

## 设置项

在「设置」的「索引」分组中添加四个开关。旧设置文件缺少字段时采用表中的默认值。

| 设置 | 默认 | 关闭后的行为 |
| --- | --- | --- |
| 预计算排序 | 开启 | 在查询需要时计算排序，桌面只保留当前列的排列。 |
| 索引创建时间 | 关闭 | 省去创建时间列和已知值位图。本机 HTTP 和 CLI 无法按创建时间筛选，普通搜索返回 `createdUtc: null`。 |
| 索引修改时间 | 开启 | 省去修改时间列。桌面隐藏该列，本机 HTTP 和 CLI 无法按修改时间排序或筛选，普通搜索返回 `modifiedUtc: null`。 |
| 索引文件大小 | 开启 | 省去文件大小列和大文件大小旁表。桌面隐藏大小列，文件夹大小统计和空间分析停用。本机 HTTP 和 CLI 无法按大小排序或筛选，普通搜索返回 `sizeBytes: null`。 |

沿用设置页的统一保存。四项索引设置以一次启动为生效边界，保存后提示下次重启生效。现有设置继续按各自的生效规则处理。文件大小关闭时，「计算搜索结果中的文件夹大小」保留勾选偏好并显示依赖说明。重新开启文件大小后，根据该偏好恢复目录统计。关闭列对应的排序时，桌面改用名称升序。

创建时间用于本机 HTTP 和 CLI 的范围筛选和结果字段。桌面搜索的名称、路径匹配和排序，空间分析，以及按 NTFS 引用和 USN 水位更新文件身份均可在没有创建时间时运行。

## 排序

开启预计算时，在卷建立或恢复时为可用列生成排列。关闭时，按需排序并复用现有的行号排列、比较规则和跨卷归并。切换列后，旧排列在已开始的查询完成或取消后释放。升降序、翻页和新搜索词复用当前列的有效排列。已知值的顺序可反转，未知值继续位于末尾。

HTTP 和 CLI 查询复用匹配的排列。请求其他排序列时允许计算并临时持有结果，查询结束后释放。排序工作受现有查询取消和并发约束，过期的索引视图不能重新发布缓存。小结果继续复用现有的匹配项排序。关闭预计算时，目录大小合计可继续用于显示，目录大小排列也只在需要按大小排序时生成并持有。

## 采集、快照与接口

以当前进程生效的设置约束初扫、快照恢复、USN 更新及索引合并。文件名、父目录、NTFS 身份及索引可见性始终保留。把可选元数据与基础记录分开存储，禁用的列无需分配与索引行数成正比的内存。保存和恢复使用已生效的索引布局。

旧退出快照按其格式已有的字段恢复，仅把启用的字段放入内存。新快照分卷记录哪些元数据采集已启用，用于区分配置关闭和单条记录缺值。启用新字段时，包含该字段的卷从快照恢复并补读 USN。缺少该字段的卷按现有采集流程补齐并报告原因，其他卷照常恢复。只关闭字段或切换预计算策略可以复用可用快照。继续读取现有静态 `.ntidx` 文件，保留静态 CLI 命令的行为。

本机搜索接口遇到显式使用已关闭字段的筛选或排序时返回 400 和对应设置提示，CLI 沿用现有错误处理。普通搜索保持结果字段名称，以 `null` 表示缺值。搜索仍返回精确匹配数，分页、硬链接、实时增量以及目录和文件操作沿用原有语义。

## 验收

- 验证缺省值、四项独立保存和重启生效。验证大小依赖、桌面列与排序回退、API 和 CLI 的允许与禁用行为。
- 在初扫、快照恢复、增量和合并后核对禁用字段未分配持久数组。验证旧快照恢复、含字段快照复用、缺字段卷补齐，以及停机期间的变更回放。
- 验证预计算与按需排序返回相同的精确总数与有序页面。覆盖跨卷、升降序、切列、文件夹大小、并发查询、取消和 USN 更改后更新排列。
- 使用同一份真实快照对照基础索引、私有提交、冷启动和切列峰值及查询延迟。只运行相关的核心、设置、HTTP／CLI 和 Windows 窗口用例。同步更新随包手册并核对便携版。
