# NTFS Search 桌面界面重构

## 窗口与操作

Tauri 和 Vue 提供新的 Windows 主窗口。顶部是一行搜索框和「完整路径 / 仅名称」切换，默认匹配完整路径。启动后可以直接输入，`Ctrl+F` 聚焦搜索框，输入时实时更新结果。保留现有的空格和双引号查询语义。

中间显示名称、完整路径、大小和修改时间。点击列标题排序，再点一次反转方向。结果表支持键盘选择，双击结果或按 `Enter` 打开选中项。右键菜单提供打开、打开所在目录和复制完整路径。长路径显示省略号，完整内容可查看和复制。

底栏显示精确匹配数、用户查询耗时、页码和翻页控件，每页最多 200 条。搜索条件或排序变化后回到第一页。后台更新合并刷新，保留用户查询耗时、当前页、仍存在的选中项和滚动位置；末页失效时退到最后一个有效页。初始加载、无匹配和索引出错各有对应提示。

底栏上的「索引状态」可展开逐卷进度和错误详情，以及重新扫描和取消采集操作。部分卷加载成功时即可查询，授权被取消时仍可查询已经加载的索引。

## 桌面与后端

Tauri 承载 Vue 窗口并管理同目录的 .NET 后端子进程。后端复用 `SearchCatalog`、`QueryRefreshState`、自动卷加载、管理员采集和诊断入口，移除 WPF 和 `Dispatcher` 依赖。搜索与索引状态通过进程间通信按请求返回，一次只传输当前页结果。新查询可以取消或替换过时请求，后台刷新沿用当前查询。Windows 文件操作使用结果原始路径。

应用按普通权限启动，采集沿用 Windows UAC。关闭窗口时停止后端及其采集任务。数据仍位于应用目录的 `Data`，可读取现有快照、检查点与日志，继续从已保存的 USN 位置恢复。启动或查询失败时在窗口内说明原因，用户可以看到各卷状态及适用的重试入口。

Windows x64 便携包包含桌面程序和后端，渲染使用系统的 WebView2 Runtime。使用仓库现有 Windows 构建入口产出发布目录，包内提供用户操作说明。

## 验收

运行现有核心测试，验证正常启动后自动发现和逐卷加载、搜索及四列双向排序、精确计数、翻页和后台更新。使用 Windows 桌面窗口验证启动焦点、键盘、右键操作、窄窗口、索引详情及退出清理。用隔离数据目录检查旧缓存恢复，比较同机同数据下的搜索延迟和整体进程内存，新版包含 Tauri、WebView2 和 .NET 后端。
