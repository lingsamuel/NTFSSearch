# 搜索结果的匹配加粗与横向滚动

## 匹配加粗

- 在名称和完整路径两列加粗命中的原始文字，保留原有大小写。含空格的普通查询按词加粗，例如 `hello world` 分别加粗 `hello` 和 `world` 的每处命中，即使它们不相邻或分别出现在目录和名称中。双引号搜索按连续短语加粗，例如 `"hello world"` 连同中间的空格加粗。匹配不区分大小写，重叠的片段合并。
- 「完整路径」模式可加粗父目录和名称中的命中。「仅名称」模式下，普通词在名称列以及完整路径末尾的名称部分加粗。含反斜杠的搜索条件沿用现有的路径限定规则，跨目录和名称的匹配在完整路径列连续加粗，在名称列只加粗重叠部分。空查询使用普通字重。
- 后端复用搜索分词和匹配规则，只为当前页结果计算加粗范围。范围与对应查询结果一起更新，覆盖翻页、排序和实时刷新。界面以纯文本片段渲染，词段加粗后仍可省略、悬停查看和复制完整路径。

## 路径分隔符

- 搜索条件中的 `/` 按 `\` 匹配，也支持同一条件内混用两种分隔符。桌面、HTTP 和 CLI 使用同一套搜索解析。搜索框保留输入，结果及复制路径使用原始 Windows 路径，加粗使用同一套匹配结果。
- 分隔符等价规则也适用于双引号内的短语。例如 `"D:/Project Files/report.txt"` 与 `"D:\Project Files\report.txt"` 返回相同结果并加粗相同片段。

## 列宽与滚动

- 拖动任一列只调整对应列和结果表总宽度。搜索栏、结果滚动容器、底栏各自贴合窗口内容宽度。表头与结果行共用横向滚动区域。
- 总列宽超出结果区时可以使用横向滚动条、触控板横向手势或 `Shift` 加滚轮。按住 `Shift` 时，滚轮向上往左、向下往右，达到当前方向的边缘时停住。普通纵向滚轮继续上下滚动。

## 验收

- 验证未加引号且不相邻的多个关键词、双引号短语、大小写、父目录命中、路径限定及仅名称模式。验证含空格的路径使用正斜杠、反斜杠或混用时返回并加粗相同结果。翻页和刷新后仍按当前结果对应的查询加粗。
- 在窄窗口拖宽一列，验证最右列可见、表头和结果行对齐，以及搜索栏和底栏宽度及位置稳定。验证 `Shift` 加滚轮可向两侧滚动，普通滚轮可纵向滚动。
