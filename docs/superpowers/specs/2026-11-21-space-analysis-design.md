# 基于现有索引的空间分析

## 操作与统计口径

主窗口增加「空间分析」入口。打开后从已有索引的本地 NTFS 卷中选一个，默认显示按盘符排序的第一个已就绪卷。卷根显示其直接子目录和文件的矩形树图。点选目录进入下一级，可以通过面包屑返回。悬停或键盘聚焦时显示名称、逻辑大小和占当前目录的比例。沿用现有大小格式，详情显示精确字节数，文件可通过现有操作打开所在目录。

视图标明「逻辑大小」。目录大小等于其所有已索引后代文件的逻辑大小之和。每个硬链接按所在路径计入所在目录，同一个文件的多个链接路径会分别计入。大小缺失的条目单独计数并提示，已知大小为零的条目没有矩形面积。

树图展示最多 200 个正大小的子项，按大小降序选取，其余正大小子项合并为「其他」，其大小仍计入比例和目录总计。空目录、合计为零、等待索引和统计失败各有对应提示。离开空间分析后可回到原来的搜索条件和结果位置。

## 统计与刷新

复用搜索后端已发布的单卷只读索引视图。首次选择卷时，在后台读取各层的有效行，以完整 NTFS 文件引用识别父子关系。先汇总各目录直接包含的文件，再从子目录向父目录合计。通过现有大小旁表读取大文件，累计值保留精确字节数。按目录保存汇总和导航所需数据，文件元数据从既有索引读取。桌面端通过现有消息通道获取当前目录有限数量的条目，在 Vue 中按比例布局矩形。

空间分析只保留当前卷的统计。切卷或返回搜索时取消旧任务，并释放其持有的统计及索引引用。返回搜索会暂停空间分析，保留盘符、目录、排除项及树图的展开和细节层级。重新显示时按最新索引恢复统计。卷索引可以从磁盘快照恢复，加载完成后即可用于统计。采集补齐 USN 或发布后续变更时，合并当前卷的通知，根据新旧视图的有效记录和父子关系计算差异。所有变化应用完毕后，按同一个索引版本提交统计和树图。普通增删或改大小更新对应目录和祖先，目录移动把其子树总计转到新的祖先链。整卷视图被替换或索引合并使差异无法低成本取得时，可从新视图在后台重建统计。保留仍存在的当前目录，删除后回到最近仍存在的上级。当前卷卸载后，按默认选卷规则切换视图。

选择按需内存汇总，是为了直接复用已完成的采集和现有退出快照。把汇总提前到启动或采集过程中能缩短打开视图的等待，但会增加正常启动的成本。每次进入目录都从卷索引重新汇总则会重复读取同一子树。统计在进入空间分析后开始，在浏览当前卷时复用结果，整个过程以已发布的内存索引为数据来源。

## 验收

- 用受控卷核对根目录和下级目录的准确字节数，覆盖硬链接、空目录、零大小、未知大小及大文件。验证文件新增、改大小、移动和删除，以及目录移动、删除和索引层合并后的统计。
- 在 Windows 桌面验证选卷、逐级进入和返回，以及关闭视图后恢复搜索。切卷、返回搜索或卸载卷时，旧请求的结果不得覆盖当前视图。
- 用现有九卷、约 3500 万条记录的实盘索引测量按卷首次出图耗时、下钻耗时、增量更新时间及额外内存，并确认打开空间分析不会触发重新采集。搜索和正常退出快照一同回归验证。
