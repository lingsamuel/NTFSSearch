# 设置页与搜索服务管理

需求已确认。

## 设置入口

主窗口增加「设置」入口，托盘右键菜单也增加「设置」。从托盘打开时恢复原窗口并进入设置页，关闭设置页后回到之前的视图。现有「索引状态」中的设置保留在原位置。

## 搜索服务

设置页提供「启用 HTTP 搜索服务」和「端口」，并显示服务状态和实际访问地址。默认启用，默认地址为 `127.0.0.1:18791`。

「保存并应用」立即启停服务或切换端口，将成功应用的配置保存到便携版的 `Data/settings.json`。端口非法或被占用时显示原因，保留原先可用的服务和配置。

「重启服务」重新启动当前的 HTTP 监听。桌面查询和磁盘采集继续使用同一份实时索引，HTTP 调用可能短暂中断。

同目录的 CLI 自动查找已保存的端口。现有 `NTFS_SEARCH_PORT` 继续优先于保存的端口，设置页显示覆盖后的实际地址。

## 测试示例

页内提供一行可在 Linux 或 WSL 执行的 curl 示例，地址随实际端口更新。示例按完整路径搜索 `C:\Windows\explorer.exe`。

```sh
curl -sS --json '{"text":"C:\\Windows\\explorer.exe","limit":1}' http://127.0.0.1:18791/v1/search
```

Windows 系统卷的索引就绪后，响应会返回匹配文件的完整路径。

## 验收

- 从主窗口和托盘右键进入同一个设置页。
- 使用隔离的演示索引验证关闭、启动、切换端口、重启和端口冲突，核对索引与后端进程继续运行。
- 验证重开程序后设置仍生效，CLI 可读取新端口，原有环境变量覆盖仍生效。开发时只运行相关的专项测试。
