# 在空间分析中直接打开目录

空间分析增加目录地址栏。可输入或粘贴已索引的本地 NTFS 绝对目录路径，例如 D:\Games\SteamLibrary，也可以输入卷根 D:\。按 Enter 后直接以该目录为根显示树图。跨卷路径自动切到对应卷。通过矩形或面包屑导航时，地址栏显示当前完整路径。

复用已发布的卷索引和目录身份关系定位路径，并继续使用现有逻辑大小统计及增量刷新。输入允许资源管理器复制路径时附带的引号和目录末尾的反斜杠。优先匹配完整路径的原大小写，兼容能唯一定位的大小写差异。

输入的卷仍在加载时显示索引状态。输入文件、无效路径、未索引路径或存在歧义的路径时在地址栏提示，保留当前树图，方便修改后重试。该方案的统计数据来自现有索引。

验收覆盖当前卷目录、跨卷目录、卷根、空目录、带空格和引号的路径、错误输入后的重试，以及输入路径和面包屑之间的同步。
