# 桌面高级搜索与顶部菜单

- 主窗口的顶部菜单沿用搜索界面的配色和弹出层样式。「搜索」提供「高级搜索…」「匹配完整路径」「仅匹配名称」，后两项互斥。「工具」提供「设置…」。
- 搜索框旁用一个下拉菜单多选「文件夹」「文件」，全选时显示「全部」，菜单保持展开以便连续勾选。仅选一类时筛选整份查询结果，两项都取消时显示零条。空间分析在搜索页和分析页之间一步切换，各自保留会话状态。
- 高级搜索以独立对话框编辑创建日期、修改日期、逻辑文件大小和后缀多选。日期使用本地日期，所选起止日均包含。大小用字节表示，上下限均包含。未索引的字段在对话框提示并禁用。支持应用、取消和清除，已应用条件数在结果底栏显示。
- 后缀选项从全索引的可见文件动态汇总，忽略大小写，使用最后一个点后的后缀，并提供「无后缀」选项。打开对话框时异步获取，复用同一索引版本的汇总。清空后缀选择表示任意后缀。后缀仅约束文件，文件夹由类型选项控制。
- 各条件取交集，复用现有匹配、精确计数、排序、分页和索引刷新。没有筛选时走原有查询路径。桌面过滤条件通过已有的本地消息通道提交。
