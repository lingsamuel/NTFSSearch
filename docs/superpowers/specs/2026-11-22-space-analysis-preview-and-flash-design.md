# 空间分析的细节层级、临时展开和变更提示

## 自动展示

新视图默认显示两层。用户可在「细节」选项中选择一至三层，或用 Ctrl 加加号、减号调整。排版按条目逻辑大小分配矩形，并依据矩形的实际像素大小决定能否容纳下一层。窗口尺寸改变时重新判断。自动展示可以同时出现在多个文件夹内。

## 临时展开

单击当前树图的顶层文件夹，在该矩形内允许比当前自动细节多一层。地址栏和面包屑仍指向当前视图的根目录。单击另一个顶层文件夹时，之前的文件夹恢复自动显示层级，新的文件夹临时多显示一层。再次单击已展开文件夹的标题可收起。任一时刻有零个或一个文件夹处于临时展开状态。

双击文件夹将它设为视图根目录，包括临时展开区内显示的子文件夹。在临时展开区内单击子文件夹只选中它。双击顶层文件夹时，临时展开期间的布局变化应保留可靠的双击目标。切卷、深入或返回上级时收起临时展开。索引刷新后，如果展开的目录仍在当前树图中，则继续显示其最新内容。

展开区域使用现有矩形布局和逻辑大小统计。后端从同一版已索引的目录树读取该文件夹的直接子项，沿用当前每层的显示上限。快速切换时以最近一次单击为准。

顶层目录标题用加减号表明展开手势。单击标题立即响应，自动展示的子项留在标题下方。临时展开允许显示更小的子项，底栏标明正在临时展开的目录，也适用于子项已经全部可见的情况。

## 实时闪烁

已显示的顶层文件夹内有文件新增、写入或路径变化时，该文件夹短暂高亮一次。例如当前视图根为 D:\Games，D:\Games\A\Cache\log.txt 写入后，高亮顶层的 A。文件从一个顶层文件夹移到另一个时，两个仍可见的受影响文件夹各高亮一次。一个刷新批次中同一文件夹的多条通知合并。

复用已生效的 USN 文件变更通知及索引中的父目录身份。即使文件写入前后逻辑大小相同，收到对应变更通知时也可高亮。首次打开、切卷、导航和单纯的索引合并只刷新内容。高亮仅发给变更前后都在当前树图中显示的顶层文件夹。Windows 启用减少动画时采用短暂的静态高亮。

## 验收

- 验证默认自动显示子项，调整细节层级和窗口尺寸时重新排版，多个文件夹可同时显示自动细节。

- 在真实 Windows 窗口验证单击 A、再单击 B 后只展开 B，重复单击可收起，双击进入后地址栏和面包屑同步。核对快速点击、展开区双击子目录和展开状态下的实时刷新。
- 用受控索引验证深层文件新增、同大小写入和跨目录移动映射到正确的可见顶层目录，同批重复变更只高亮一次。验证纯导航和索引重建时不会触发高亮。
