# 即时切换预计算排序与跳过本次退出保存

## 预计算排序即时生效

在设置页修改「预计算排序」并保存后，当前进程立即采用新的策略。设置页将它标明为保存后即时生效。创建时间、修改时间和文件大小仍使用下次重启生效的提示。只修改预计算排序时，保存后无需显示待重启状态。

- 关闭后，停止为非当前列预计算普通行与目录大小排列。桌面继续复用当前列已有的排列，尚无排列时按需计算。在途查询读完已取得的排列后，释放其持有的旧排列。
- 开启后，从已发布的内存索引后台按卷为可用列补建排列。等待补建期间，查询可复用已准备好的排列，也可按需计算。利用现有的比较、归并和后台任务让位逻辑，按相同规则处理目录和文件混排。
- 文件与目录记录继续由原索引维护。恢复、全卷采集、USN 增量和合并发布的新视图采用当前排序策略。只接纳与当前策略和视图对应的后台结果。连续切换取消过时任务，旧任务完成时不能重新挂接排列。
- 设置成功写入后才应用新策略。保存失败时继续使用原策略。仅改预计算排序继续使用已有的 HTTP 监听，HTTP 超时按当前生效策略选择。结果的精确计数、排序规则和分页沿用现有语义。

## 此次不保存

从托盘退出进入索引保存界面后，显示「此次不保存」。按钮只作用于本次退出。后续退出按已保存的「退出时保存索引」偏好处理。

- 正在准备退出或正在压缩写入时点击，显示「正在跳过本次保存…」并禁用重复点击。后端在退出期间继续接收这条控制请求。停止或取消本次临时快照写入，关闭文件句柄并清理临时文件，然后正常退出。
- 临时快照完整写入并刷盘后，保存任务进入最终替换阶段。此时禁用按钮并显示「正在完成保存…」。取消与替换同时发生时，由后端以同一个提交边界判定。取消先取得该边界就保留旧快照。替换先取得该边界就完成本次保存。
- 中途跳过时保留上次完整的 `index.ntsnap`。首次保存也可跳过，下一次启动按正常采集流程处理。正常保存继续使用现有原子替换。真实写入失败沿用原有错误反馈。

## 验收

- 在同一次运行中关闭、重新开启、连续切换预计算排序。验证界面提示、排序内存引用释放、后台任务取消、旧视图结果不能重新发布，并与预计算结果对照精确总数和排序。覆盖大小混排、HTTP 并发、列切换、分页和实时更新。
- 在保存准备阶段和已经写入部分数据时分别跳过。验证后端正常退出、旧快照逐字节保持、无残留临时快照、退出保存偏好可在下次启动和退出时继续使用。覆盖首次保存、重复点击与最终替换的竞态，以及正常保存仍可恢复。
- 在 Windows 实窗中验证按钮和状态反馈。用隔离数据运行相关排序、设置、退出快照和 HTTP／CLI 用例，并更新随包手册。
