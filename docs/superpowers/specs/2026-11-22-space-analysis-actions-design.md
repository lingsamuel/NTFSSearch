# 空间分析的右键操作与临时排除

- 真实文件和目录共用搜索结果的右键操作定义及原生操作入口，提供「打开」「打开所在目录」和「复制完整路径」。目录由资源管理器打开，文件沿用 Windows 默认应用。文件另有「打开方式…」，未关联应用时「打开」也调用系统应用选择。现有树图的单击和双击手势继续可用。
- 「临时排除」按当前卷及所选路径生效。排除文件或整个目录子树后，重新计算所有受影响的祖先合计、各层矩形以及「其他」。同一文件的硬链接只排除所选路径。父子排除相互独立，恢复父目录时保留对子项的排除。
- 工具栏的「已排除 N 项」可以逐项恢复或全部恢复。排除跨目录、磁盘和搜索视图切换保留，随空间分析会话结束而清空。地址栏指向已排除目录时给出恢复提示。实时更新使用同一份排除规则。
- 矩形的大小标签附带占当前视图目录的比例。矩形与底栏提示复用自适应单位，展开目录保留底色和键盘焦点指示。
- 复用卷索引和目录统计，在每次读取时应用少量排除项。优先按文件引用定位路径，文件被替换后按名称排序定位同路径的新记录。仅扣除每个有效排除项一次。用受控索引验证层级扣减、硬链接、父子排除与刷新，再用 Windows 便携版验证菜单、应用选择及树图交互。
