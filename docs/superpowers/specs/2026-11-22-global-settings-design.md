# 设置页统一保存

## 设置项

- 「搜索」增加「计算搜索结果中的文件夹大小」，默认开启，沿用 0.15.0 的行为。关闭并保存后取消正在执行的目录统计，释放搜索持有的目录合计、排序和当前页引用，停止为后续卷构建统计。当前结果恢复为仅显示和排序文件大小，文件夹大小显示 `—`，按大小排序时视为未知。再次开启后，从现有内存索引在后台按卷计算。这个开关只控制搜索结果，空间分析仍可独立按需统计。
- 「索引」增加「退出时保存索引」，读取现有退出偏好。索引状态中的「退出时不保存索引」保留现有文案、位置和即时保存行为。两个入口共用 `SkipExitIndexSave`，勾选含义相反。任一入口成功保存后，另一处显示对应状态。关闭退出保存时继续保留上次保存的快照。
- 「搜索服务」保留启用开关、端口、监听状态、实际地址、重启和查询示例。

## 保存与应用

设置页提供一个页面级的「保存并应用」按钮。设置项编辑先保存在页面中，点击保存后一次写入 `Data/settings.json` 并应用，返回前未保存的修改随页面关闭丢弃。重启服务使用已保存的配置，页面中的待保存修改保留。

设置页和索引状态按提交顺序保存。偏好写入期间暂停另一入口的编辑，防止用旧值覆盖刚提交的设置。正常退出先处理已接收的设置，再依据最新偏好决定是否写入索引快照。

只有 HTTP 配置发生变化时才应用 HTTP 监听变更。变更端口时复用现有的候选监听和原子写入流程。端口验证、绑定或写入失败时，保留已经生效的配置及页面输入，提示对应原因。仅修改目录大小或退出保存时，服务原有的监听状态不会阻碍保存。

目录大小设置变更后按当前搜索词、排序方式和页码刷新结果。当前选中项仍出现在该页时保留选中。关闭期间取消悬挂的统计任务，与旧状态关联的统计结果不得重新发布。重新开启时沿用现有的暂排状态和逐卷更新。

## 验收

- 检查旧配置缺少目录开关时默认开启。保存关闭后即时更新列表和大小排序，在本次会话及重启后保持关闭。验证任务被取消、统计引用可回收、未创建新的搜索统计，以及重新开启后从已有索引补回大小。
- 检查页面级按钮同时保存三组设置。验证仅修改本地设置时 HTTP 监听继续响应，端口冲突时保留已保存配置，重启服务使用已保存配置。验证退出保存的两个入口双向同步，并覆盖实际退出保留或更新快照的行为。
- 仅运行相关的设置、目录大小、Windows 实窗及本机搜索用例。更新随包手册并核对 Windows 便携版。
