# 退出快照的分卷 Zstandard 压缩

## 写入和恢复

正常退出保存时，每个卷独立用 Zstandard 等级 3 压缩，与命令行参数 `-3` 对应。一次写一个卷，使用单线程编码。逐卷流式写出压缩结果，最终原子提交一份退出快照。

新格式使用 NTSEXIT3 标头。卷目录记录存储长度、解压长度和压缩数据的 SHA-256。启动时按卷校验压缩块、流式解压和重建排序，继续并行加载各卷。损坏的卷进入现有的单卷恢复流程。解压直接进入索引读取，工作内存随流缓冲和同时加载的卷变化。

启动读取新格式。升级时，未压缩快照按无可用快照处理，本次从 NTFS 建立索引。用户开启「退出时不保存索引」时，沿用现有跳过行为。

## 验收

- 核对索引输入和压缩快照恢复出的有效记录、父目录关系、USN 水位以及四列查询顺序。
- 覆盖多个卷并行恢复、单卷数据损坏和保存中断，确认健康卷继续恢复，原子提交前的旧快照仍可用。
- 用同一份九卷实盘索引对比正式路径的保存耗时、落盘体积、加载并重建排序耗时，以及额外内存。未压缩基线路径仅用于隔离诊断。
