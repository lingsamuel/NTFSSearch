# 桌面本地化与语言设置

设置的第一个标签为「通用」，其中的「语言」提供「跟随系统」、简体中文和 English。旧配置和新配置默认跟随 Windows 显示语言。优先匹配完整语言标签，然后匹配语言。简体中文是首批中文译文，未匹配的系统语言使用英文。保存沿用整页设置流程，成功后切换桌面界面和托盘菜单，保留当前搜索和索引状态。

桌面覆盖搜索、高级搜索、设置、空间分析、索引状态、应用提示和托盘菜单。文件名、路径、扩展名和系统返回的诊断细节按原文展示。语言标签、译文与可替换参数从仓库 `locales` 目录下的 JSON 读取。各语言名称使用该语言自身的写法。新增一种语言时随构建发现，提供部分译文时使用英文补齐。普通版和无 HTTP 服务版使用同一语言设置和资源。

在提交前运行语言文件检查，验证 JSON、重复键和可替换参数。内置中英文分别验证设置页面、自动匹配、切换、重启持久化和活动窗口状态。单独的贡献指南说明如何提交语言文件。
