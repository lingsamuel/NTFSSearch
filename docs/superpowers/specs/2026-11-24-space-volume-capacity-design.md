# 空间分析磁盘容量与设置标签页

空间分析的磁盘选择器在盘符右侧显示 `已用大小 / 总大小 (百分比)`。展开时逐盘显示，收起时显示当前盘。背景用主题浅色从左到右填充相同比例。切换到剩余空间后，容量文字、百分比和填充比例一起切换。无法读取容量的磁盘仍可选择，并只显示盘符。

容量来自 Windows 卷的总大小和空闲空间。进入空间分析及展开选择器时在后台刷新。容量刷新独立于树图查询和目录钻取，现有索引的发布仍决定哪些磁盘可选。容量单位沿用桌面端已有的格式。

设置分为「搜索」「索引」「空间分析」「搜索服务」四个标签页。无 HTTP 服务版隐藏「搜索服务」。空间分析入口的设置按钮直接打开对应标签。从主窗口或托盘打开时默认进入「搜索」。切换标签保留整页草稿，统一使用「保存并应用」。

「空间分析」提供「显示磁盘容量」「容量显示方式」「显示背景用量条」。默认显示已用空间并绘制背景。关闭容量显示时保留两个子选项的偏好，重新打开后恢复。旧配置按上述默认值加载。设置沿用现有的写入队列和配置文件，保存后立即生效。

验证旧配置默认值、设置持久化、容量读取、已用和剩余模式、开关组合、跨标签保存、选盘键盘操作及无 HTTP 服务版的标签页可见性。
