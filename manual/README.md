# NTFS Search 使用说明

## 启动

解压 Windows x64 便携包，双击「启动搜索.cmd」，或打开顶层的 `NtfsSearch.App.exe`。系统需要 WebView2 Runtime 和 .NET 10 Runtime。自包含便携包内含 .NET Runtime。

程序会自动发现本机已就绪的 NTFS 磁盘。Windows 可能显示 UAC 授权提示，确认后才能采集磁盘和持续监控。一个卷建立或加载索引后即可搜索该卷。

## 搜索文件和文件夹

- 打开窗口即可输入。默认匹配完整路径，搜索框右侧可切换到「仅名称」。按 `Ctrl+F` 回到搜索框。
- 输入 `hello world` 匹配同时包含两条条件的结果。输入 `"hello world"` 匹配包含空格的连续文本。
- 点击名称、完整路径、大小或修改时间的列标题排序，再点一次切换方向。拖动列标题右边缘可调整宽度。文件大小自动切换单位，悬停可查看精确字节数。底栏显示匹配总数和当前页，可逐页查看。
- 文件使用 Windows 对应类型的图标，目录使用目录图标。
- 在搜索框按向下键进入结果表。双击结果或按 `Enter` 打开选中项。右键选择「打开所在目录」会在资源管理器中打开父目录并选中该项。条目已移动或删除时，窗口会显示错误提示。右键菜单或 `Ctrl+C` 可复制完整路径。

## 查看空间分析

点击搜索框右侧的「空间分析」，选择已有索引的磁盘。矩形面积随逻辑大小变化。默认显示两层，空间足够的文件夹会自动显示子项。可用「细节」或 `Ctrl` 加加号、减号调整层级。

单击任意层的文件夹可就地展开，继续单击子目录可逐层展开。切到其他分支会收起上一条分支的临时展开，保留共同上级。空间不足时可双击文件夹，或聚焦后按 `Enter` 放大目录，点击面包屑返回上级。矩形上的大小后显示占当前目录的比例。矩形、底栏和悬停提示均使用自适应大小单位。点击文件在资源管理器中定位。已显示的顶层文件夹内有文件变化时，矩形会短暂高亮。

右键文件或文件夹可打开该项。文件可用「打开方式…」选择应用，未关联应用的文件也会在打开时提示选择。

右键选择「临时排除」可从树图中移除文件或整个文件夹，并扣除其在各级父目录中的大小。点击「已排除 N 项」可逐项或全部恢复。切换目录和磁盘保留排除项，返回搜索后清空。

在地址栏可粘贴已索引的本地目录路径，例如 `D:\Games\SteamLibrary`，按 `Enter` 或点击「打开」。输入 `D:` 可直接查看卷根。输入跨卷目录会自动切换磁盘。目录无法定位时，提示会出现在地址栏下方，当前树图可继续使用。

目录大小是其中已索引文件逻辑大小的合计，硬链接按路径分别计入。小条目可合并为「其他」，其大小仍计入合计。打开空间分析或切换磁盘时，程序用已有索引汇总选中卷。后台索引更新后树图会一起刷新。点击「返回搜索」保留原搜索位置。

## 查看和处理索引状态

底栏的「索引状态」显示已索引数量、各卷进度和错误原因。可在此重新扫描磁盘或取消采集。取消采集后仍可搜索已经加载的索引。

启动时，每个卷会分别显示快照检查、读取、重建排序和 USN 补读阶段。实时监控状态会说明本次从快照恢复或经过全卷采集。只有无可用快照、USN 失效需要重建或手动重扫等情况才进行全卷采集。

## 退出和移动

窗口正常关闭时会显示索引保存进度。各卷索引完整后，程序在正常退出时分卷压缩文件元数据，并写入便携版顶层的 `Data/index.ntsnap`。下次启动时逐卷恢复并重建排序，再补读停机期间发生的变化。

在「索引状态」开启「退出时不保存索引」，程序退出时保留上次保存的快照。开关会记在 `Data/settings.json`，下次启动沿用。关闭开关可恢复正常退出保存。

0.10.0 启用新快照格式，升级后的首次启动从 NTFS 卷建立索引。正常保存一次后，下次启动可使用压缩快照。移动便携版时可带上顶层的 `Data`。保存快照需要程序目录可写。
